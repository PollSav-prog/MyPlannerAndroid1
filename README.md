# Мой планировщик — версия для Android

Мобильная версия планировщика: календарь, задачи, правая панель из 9 кнопок, «капелька»-предупреждение,
точные напоминания с мягким двухнотным сигналом (повтор каждые 10 минут), голосовое создание задач,
погода и часы, светлая/тёмная тема, русский / English / Deutsch / Français.

Технологии: Kotlin, Jetpack Compose, SQLite, AlarmManager. Android 8.0 и новее.

> **Статус.** Код написан, но в среде разработки не было Android SDK, поэтому **приложение не компилировалось
> и не запускалось на телефоне**. Проверены: корректность XML, баланс скобок, полнота переводов (246 строк × 4 языка).
> Первая сборка может показать ошибки компиляции — пришлите текст ошибки, я исправлю.

## 1. Как получить APK (программы для разработки не нужны)

1. На https://github.com нажмите **New repository**, имя — например `MyPlannerAndroid`.
   Это должен быть **отдельный** репозиторий, не тот, где лежит Windows-версия.
2. Загрузите в него всё содержимое этой папки, включая скрытую папку `.github`
   (если она не загружается — создайте файл `.github/workflows/android.yml` вручную: **Add file → Create new file**).
3. Вкладка **Actions → Build Android APK → Run workflow**.
4. Через 5–10 минут откройте завершённый запуск, внизу в **Artifacts** скачайте **MyPlanner-APK** (zip) и распакуйте — внутри `app-debug.apk`.
5. Красный крест — откройте упавший шаг и пришлите текст ошибки.

## 2. Установка на телефон

1. Перенесите `app-debug.apk` на телефон (почта, Telegram «Избранное», кабель).
2. Откройте файл. Android спросит разрешение «Установка из неизвестных источников» для этого приложения — разрешите.
3. Нажмите **Установить**, затем **Открыть**. Разрешите уведомления.
4. Чтобы напоминания приходили точно: *Настройки → Приложения → Мой планировщик → Батарея → Без ограничений*
   (на некоторых оболочках — Xiaomi, Huawei, Samsung — ещё включите «Автозапуск»).

## 3. Как пользоваться

- **Календарь** сверху: красный круг — выбранный день, точка — есть задачи, красная капелька — скоро событие.
  `‹ ›` — месяцы, `« »` — годы, «Сегодня» — вернуться к текущей дате.
- **Список «МОИ ПЛАНЫ»**: нажатие выбирает задачу, двойное — редактирует, долгое — меню (перенести, удалить).
- **Правая панель (9 кнопок, долгое нажатие — подсказка):** добавить · изменить · выполнено · повторение ·
  звук · тихий режим · погода · история · язык.
- **Микрофон вверху** — голосовое создание задачи: скажите «Завтра в три часа позвонить врачу». Если час неоднозначен
  («в три часа»), приложение спросит утро или вечер, затем озвучит и спросит подтверждение. Можно набрать фразу текстом.
- **Шестерёнка** — настройки: тема, озвучивание, капелька (время и текст), тихие часы, резервная копия.
- **Напоминание:** уведомление + сигнал в назначенное время; пока не нажато «Выполнено», повтор каждые 10 минут
  (интервал меняется в «Звук»). В уведомлении есть кнопки «Выполнено», «Отложить на 10/30 мин».
- **Пропущенное** (телефон был выключен) показывается одним общим уведомлением.
- **Громкость сигнала** — системная громкость уведомлений.

Данные хранятся на телефоне. Копия создаётся автоматически раз в сутки (последние 7); вручную — в настройках
(сохранить/восстановить файл).

## 4. Ограничения

- Распознавание речи делает служба телефона (обычно Google); для некоторых языков нужен интернет. Озвучивание требует установленного голоса языка.
- Приложение собирается как debug-APK (подписан отладочным ключом) — для установки «напрямую», не для Google Play.
- Повторяющаяся задача показывается в календаре только на ближайшей дате.
- Погода из Open-Meteo по названию города; без интернета показываются последние данные.
- Не проверено на реальном устройстве: сигнал и уведомления в фоне, внешний вид, голос, поведение на разных оболочках.

## 5. Структура

```
app/src/main/java/com/myplanner/app/
  data/     модель, SQLite, настройки
  logic/    разбор фраз (ru/en/de/fr), повторения, напоминания, действия над задачами
  notify/   будильник, уведомления, приём перезагрузки
  ui/       Compose: главный экран, диалоги, голосовой ввод
  weather/  Open-Meteo
app/src/main/res/  строки 4 языков, звуки сигналов (raw), иконка
tools/gen_resources.py  генерация строк из JSON Windows-версии и звуков
```
